# Портфолио инженера по тестированию (QA)

В этом репозитории представлены мои учебные проекты, выполненные в рамках курса «Инженер по тестированию» от Яндекс Практикума.

---

###  Проект №1: Регрессионное тестирование веб-приложения
В ходе проекта был проведен полный цикл проверок стабильности системы после внесения изменений.
*   Проведение регрессионного тестирования, составление баг-репортов, проведение ретеста (retest) исправленных дефектов. 
    * [Часть 1: Тестовая документация](https://docs.google.com/spreadsheets/d/1SWHncIN9Nuu80eVDCj-eHhzBy3XENce092UXINQLvNY/edit?gid=220888493#gid=220888493)
    * [Часть 2: Баг-репорты](https://docs.google.com/spreadsheets/d/1hm9-EUpWrElUr9VGBcLVzFXNAPrOPoBaCJRQz2tHqTk/edit?gid=1186534874#gid=1186534874)
    * [Часть 3: Ретест](https://docs.google.com/spreadsheets/d/1cPJ3AV0Mq4KG_el9GKBohNReDNgJXIhTcZdCuhDEVbs/edit?gid=379530441#gid=379530441)

###  Проект №2: Тестирование новой функциональности (Фичи)
Работа над анализом требований и проектированием тестов для нового раздела веб-приложения.
*   Глубокий тест-анализ требований, применение техник тест-дизайна (Классы Эквивалентности и Граничные Значения), написание тест-кейсов и оформление баг-репортов.
*   [(КЭ, ГЗ, Тест-кейсы, баг-репорты)](https://docs.google.com/spreadsheets/d/1WC4WOQbP4avhamXNr8pOc9E0bc9ypxLUk5Za8qClaG0/edit?gid=1610041137#gid=1610041137)

###  Проект №3: Расширенное тестирование веб-сервиса
Комплексная проверка пользовательских сценариев и визуальной составляющей интерфейса.
*   Составление чек-листа на верстку, чек-листа на способы оплаты и добавление карты, проектирование тест-кейсов для кнопки «Забронировать», составление баг-репортов.
*   [(Верстка, Оплата, Тест-кейсы, баг-репорты)](https://docs.google.com/spreadsheets/d/1cKeQTK0-Lyv3ZFzHCC_7jeJ-xV72iivTvF3o2wh9m9Q/edit?gid=899462569#gid=899462569)

---
**Стек и навыки:** Google Sheets, DevTools, техники тест-дизайна (КЭ, ГЗ), баг-репортинг, тест-анализ, декомпозиция.
