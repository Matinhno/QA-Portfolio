### 🔹 Проект №6: Работа с базами данных и анализ данных (SQL)
> **Описание:** Практический курс и тренажер по составлению сложных SQL-запросов к реляционной базе данных (венчурные фонды и инвестиции).

* 🛠 **Стек:** PostgreSQL, SQL (DQL), ER-диаграммы (схемы БД), тренажер Яндекс Практикума.
* 📋 **Что было сделано:**
  * Изучена схема базы данных (ER-диаграмма), таблицы и связи между ними (`Primary Key`, `Foreign Key`).
  * Составлены и отработаны сложные SQL-запросы:
    * Объединение данных из нескольких таблиц (`INNER JOIN`, `LEFT JOIN`, `FULL JOIN`).
    * Группировка, агрегация и фильтрация результатов через `GROUP BY`, `HAVING`, `COUNT`, `SUM`, `AVG`.
    * Составление подзапросов (Subqueries) и вложенных условий фильтрации (`WHERE`, `LIKE`, `IN`, `BETWEEN`).
  * Проведен QA-анализ данных: выявление пустых значений (`NULL`), аномалий и проверка бизнес-логики на уровне БД.
